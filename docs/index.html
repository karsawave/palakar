Framework PHP 8.2+ yang ringkas dan mudah ditelusuri.

Core terdiri dari 45 file (sekitar 6.400 baris). Query di-bind dan token CSRF diperiksa secara bawaan. Dapat berjalan di shared hosting tanpa Composer.

Panduan mulai Kode di GitHub 
$ composer create-project karsawave/palakar app

Tanpa Composer? Unduh ZIP dari halaman rilis.

v0.3.3 · PHP 8.2–8.5 · BSD-3-Clause

Cocok untuk

Mempelajari cara kerja framework

Alur request dapat diikuti dari Gear.php hingga controller, tanpa container DI atau middleware.

Shared hosting

Unggah app/, panada/, dan public/, lalu arahkan document root ke public/. Composer tidak diperlukan di server.

Migrasi dari Panada 1.x

Namespace Resources\ dan struktur Controllers/Models dipertahankan. Catatan migrasi ke PHP 8.2+ tersedia di MODERNISASI.md.

Fitur inti

Routing di satu file

Gear.php, 326 baris: URL ke controller, method, dan argumen.

Query selalu di-bind

Nilai lewat placeholder. update() dan delete() tanpa WHERE ditolak.

CSRF dicek sebelum controller

POST, PUT, dan DELETE butuh token, kecuali rute di security.php.

Controller kelas biasa

Tanpa container DI dan middleware. Method yang mengembalikan array otomatis dikirim sebagai JSON.

Diuji di PHP 8.2 sampai 8.5

152 test di CI, juga dengan PostgreSQL, MariaDB, Redis, dan Memcached.

Output lewat e()

Helper e() untuk escape output di view. Aplikasi contoh memakainya untuk setiap data dari pengguna.

Contoh controller

class Hello extends Resources\Controller
{
    public function hi(string $who = 'dunia'): array
    {
        return ['hello' => $who];
    }
}

// GET /hello/hi/Budi  →  {"hello":"Budi"}
