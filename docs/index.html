Palakar 0.3.0

Framework PHP 8.2+ yang kecil dan aman. Tanpa container DI, middleware stack, template engine, atau build step: seluruh core bisa dibaca dalam semalam.

PLK 01Mulai dalam dua perintah

Mulai

  1. PLK 02Buat proyek
    composer create-project karsawave/palakar app
  2. PLK 03Jalankan
    cd app
composer serve
    Buka http://localhost:8000. Database default SQLite, tanpa setup.
  3. PLK 04Baca READMEStruktur folder, konfigurasi, dan demo Guestbook.

Contoh controller

<?php

namespace Controllers;

use Resources;

class Hello extends Resources\Controller
{
    // GET /hello/name/Budi → {"hello":"Budi"}
    public function name(string $who = 'dunia'): array
    {
        return ['hello' => $who];
    }
}

Isi core

  1. PLK 05PHP 8.2–8.5Strict types, diuji di CI untuk setiap versi.
  2. PLK 06Database PDOMySQL, PostgreSQL, SQLite. Semua nilai otomatis lewat prepared statement.
  3. PLK 07CSRF bawaanDiperiksa sebelum controller jalan untuk setiap request selain GET/HEAD/OPTIONS.
  4. PLK 08Validasi dan sanitizeInput dibersihkan otomatis; output view dicetak lewat e().
  5. PLK 09Session dan error yang amanCookie HttpOnly, SameSite, strict mode. Halaman error tidak membocorkan path saat debug mati.
  6. PLK 10Composer opsionalAutoloader sendiri tetap jalan di shared hosting tanpa Composer.
  7. PLK 11Baca core-nyaFolder panada/ di GitHub.
