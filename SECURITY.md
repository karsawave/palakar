# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| Latest `0.x` release | Yes |
| Older versions | No |

Panada Framework 1.x (the project Palakar was forked from) is not maintained
here.

## Reporting a vulnerability

**Please do not open a public issue, pull request or discussion for a
security problem.**

Report it privately through GitHub:
https://github.com/karsawave/palakar/security/advisories/new

Include, if you can:

- what is affected (file, function, version or commit)
- how to reproduce it, or a proof of concept
- the impact you expect

## What happens next

1. We confirm that we received your report within **7 days**.
2. We keep you informed while we investigate and fix it.
3. The fix and a GitHub security advisory are published together. With your
   permission, you are credited in the advisory.

If the problem also exists in the original Panada Framework, we let its
maintainers know privately before the details are published.
